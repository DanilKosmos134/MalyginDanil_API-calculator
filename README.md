# API Калькулятор с CI/CD и безопасностью

Этот проект представляет собой API-калькулятор, написанный на Python с использованием FastAPI. Проект упакован в Docker-контейнер, а для него настроен пайплайн непрерывной интеграции (CI/CD) с внедренными инструментами безопасности.

## 🛠 Технологии
* **Python** (FastAPI, Uvicorn)
* **Docker**
* **GitHub Actions** (CI/CD)
* **Semgrep** (Статический анализ кода / SAST)
* **Trivy** (Сканирование уязвимостей Docker-образов)

## 🚀 Как запустить локально
1. Собрать Docker-образ:
   ```bash
   docker build -t calculator-api:v1 .

2. Запустить контейнер (на порту 8000):

(Примечание: внутри контейнера приложение всегда работает на порту 8000. Я "пробросил" его на внешний порт 20000, так как порт 8000 у меня на Windows был занят).

    ```bash
    docker run -d -p 8000:8000 --name my-calculator calculator-api:v1

3. Открыть в браузере интерактивную документацию Swagger UI:
    http://127.0.0.1:20000/docs
